Project Overview

What is ASV?

Automatic Speaker Verification (ASV) is a biometric authentication system that uses a person’s voice to verify their identity. It analyzes unique voice patterns such as pitch, speaking style, and pronunciation.

Why Spoof Detection First?

Before feeding voice into ASV, spoof detection plays a crucial role. Without it, attackers could bypass security using replayed or synthesized voices. By filtering out fake inputs first, we ensure ASV only processes genuine speech, reducing false acceptances and strengthening system reliability. This layered defense is essential to protect against modern deepfake threats.

How Our ASV System Works

  1. Voice Input: User uploads a voice sample (e.g., .wav or .mp3).
  2. Spoof Detection: The system checks if the voice is real or spoofed.
  3. Preprocessing: LFCC features are extracted from the verified real voice.
  4. Classification: A deep learning model verifies speaker identity.
  5. Output: The system returns Real (🟢) or Fake (🔴) with a confidence score.

Key Features

  • 🎙️ Real-time or file-based voice input
  • 🧠 Deep learning model trained on ASVspoof2019 dataset
  • 📊 Output includes prediction and confidence score
  • 🛡️ Resistant to spoofing attacks (replay, synthesis, voice conversion)

Note: This system is part of a research project in deepfake detection and speaker verification. It's not intended for high-security deployment without further testing.

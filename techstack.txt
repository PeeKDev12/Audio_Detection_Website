##### TECHSTACK #####

  ### Frontend

  • React 19 – UI library
  • TypeScript – Strongly typed programming language
  • Vite – Frontend build tool and development server
  • Tailwind CSS – Utility-first CSS framework (with custom Neumorphism design system)
  • PostCSS & Autoprefixer – CSS transformation and vendor prefixing
  • Framer Motion – UI animations and modal transitions
  • WaveSurfer.js – Interactive audio waveform visualizer and player
  • Lucide React – Icon library
  • Axios – HTTP client for API requests
  • clsx & tailwind-merge – Conditional styling utilities
  ──────
  ### Backend

  • Python 3.13 – Backend programming language
  • FastAPI – Asynchronous REST API web framework
  • Uvicorn – ASGI web server
  • Starlette & Asyncio – Asynchronous concurrency and background threadpool management
  • Pydantic & Pydantic-Settings – Data validation, serialization, and settings management
  • Python-Multipart – Streaming multipart/form-data audio file uploads
  ──────
  ### Machine Learning & Audio DSP

  • PyTorch & TorchAudio – Deep learning framework and audio tensor processing for AASIST
  • TensorFlow & Keras – Deep learning framework for pretrained ResNet-34 and CNN models
  • Classification-Models (Keras) – Pretrained ResNet-34 neural architectures
  • SoundFile – Audio reading and float32 decoding
  • Librosa – Audio and music signal processing
  • SciPy – Scientific computing, signal filtering, and Discrete Cosine Transforms (DCT)
  • FFmpeg – Multimedia audio decoding for multiple formats (WAV, MP3, FLAC, M4A, OGG)
  • Acoustic Features: LFCC (Linear Frequency Cepstral Coefficients), MFCC (Mel-Frequency Cepstral Coefficients), and Raw 16 kHz Waveforms
  ──────
  ### Database & Security

  • SQLAlchemy – Database ORM (Object-Relational Mapping)
  • SQLite – Relational database for prediction audit history
  • Python-JOSE – JSON Web Token (JWT) handling
  • Passlib & Bcrypt – Password hashing and cryptography
